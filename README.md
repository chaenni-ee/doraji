# 행복과 웃음이 넘치는 우리 반 🌈

학생들에게 오늘의 아침 활동을 안내하고, 참여 현황(1~26번)을 함께 체크할 수 있는 웹앱입니다.

## 주요 기능

- **오늘의 아침 활동 자동 안내**: 한국 표준시(KST) 기준 요일(월~금)에 맞춰 활동 이름, 접속 링크, 부가 설명이 자동으로 표시됩니다. 주말에는 안내 문구가 대신 표시됩니다.
- **참여 현황 체크**: 1~26번 번호를 학생이 직접 눌러 완료 표시를 할 수 있습니다. 모든 기기에서 같은 현황이 실시간으로 공유되며, 매일 자정(KST) 기준으로 자동 초기화됩니다.
- **교사 모드**: 화면 우측 하단의 "🔒 교사 모드" 버튼으로 로그인하면 요일별 활동 이름·접속 링크·부가 설명을 설정하고, 필요 시 오늘의 참여 현황을 수동으로 초기화할 수 있습니다.

## 실행 방법

```bash
npm install
npm start
```

기본적으로 `http://localhost:3000` 에서 접속할 수 있습니다.

## 데이터 저장

- 기본값: 요일별 활동 설정과 참여 현황이 `data/state.json` 파일에 저장됩니다(로컬 개발용). Render 무료 요금제처럼 서버가 주기적으로 재시작되는 환경에서는 이 파일이 재시작 때마다 초기화될 수 있습니다.
- **`SUPABASE_URL`, `SUPABASE_SERVICE_KEY` 환경변수를 설정하면** 파일 대신 Supabase(무료 데이터베이스)에 저장되어, 서버가 재시작돼도 데이터가 유지됩니다. 배포 환경에서는 이 방식을 권장합니다.

### Supabase 연동 방법 (무료)

1. https://supabase.com 에서 무료 계정 생성 후 새 프로젝트 생성
2. 프로젝트의 **SQL Editor**에서 아래 쿼리를 실행해 테이블 생성:
   ```sql
   create table app_state (
     id text primary key,
     data jsonb not null
   );
   ```
3. 프로젝트 설정 **Project Settings → API**에서 다음 두 값을 확인:
   - **Project URL** → `SUPABASE_URL`
   - **service_role secret key** → `SUPABASE_SERVICE_KEY` (anon key 아님, 외부에 노출되지 않도록 주의)
4. 배포 환경(Render 등)의 환경변수에 위 두 값을 추가
