# 행복과 웃음이 넘치는 우리 반 🌈

학생들에게 오늘의 아침 활동을 안내하고, 참여 현황(1~26번)을 함께 체크할 수 있는 웹앱입니다.

## 주요 기능

- **오늘의 아침 활동 자동 안내**: 한국 표준시(KST) 기준 요일(월~금)에 맞춰 활동 이름, 접속 링크, 부가 설명이 자동으로 표시됩니다. 주말에는 안내 문구가 대신 표시됩니다.
- **참여 현황 체크**: 1~26번 번호를 학생이 직접 눌러 완료 표시를 할 수 있습니다. 모든 기기에서 같은 현황이 실시간으로 공유되며, 매일 자정(KST) 기준으로 자동 초기화됩니다.
- **교사 모드**: 화면 우측 하단의 "🔒 교사 모드" 버튼으로 로그인하면 요일별 활동 이름·접속 링크·부가 설명을 설정하고, 필요 시 오늘의 참여 현황을 수동으로 초기화할 수 있습니다.

## 실행 방법

```bash
npm install
npm start
```

기본적으로 `http://localhost:3000` 에서 접속할 수 있습니다.

## 교사 비밀번호 설정

기본 비밀번호는 `teacher1234` 입니다. 배포 전 반드시 환경변수로 변경하세요.

```bash
TEACHER_PASSWORD="원하는_비밀번호" npm start
```

## 데이터 저장

요일별 활동 설정과 참여 현황은 `data/state.json` 파일에 저장됩니다(최초 실행 시 자동 생성). 이 파일은 서버가 계속 실행되는 환경(예: 개인 서버, Railway, Render 등 파일 시스템이 유지되는 호스팅)에 배포해야 데이터가 유지됩니다. 서버리스 환경(예: Vercel)에서는 재배포/재시작 시 데이터가 초기화될 수 있습니다.

## 배포 팁

- Node.js가 실행 가능한 아무 호스팅(Render, Railway, 자체 서버, 라즈베리파이 등)에 올리면 됩니다.
- 태블릿/PC로 접속할 수 있는 주소(도메인 또는 사설 IP)를 학생들에게 공유하세요.
