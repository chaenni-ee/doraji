# 나만의 도라지타령

초등 음악 창작 수행평가([6음03-02])용 웹앱입니다. 학생들은 율명을 단소 소리로 듣고, 경기민요 「도라지타령」의 마지막 줄 가락을 바꿔 보고, 자기 가락이 들어간 노래 전체를 들어 봅니다. 다 만든 가락은 선생님의 구글 시트 기록표로 제출합니다.

## 기능

- **율명 소리 듣기**: 중·임·무·청황·청태·청중·청임을 누르면 단소 음색의 소리가 납니다.
- **마지막 줄 가락 바꾸기**: 교과서 정간보 빈칸 12칸에 율명을 넣습니다. "같은 음이나 바로 위·아래 음으로만 이동" 조건을 자동으로 확인합니다.
- **전체 노래 듣기**: 원래 노래와 내가 바꾼 노래를 정간보를 따라가며 들을 수 있습니다. 빠르기도 조절할 수 있습니다.
- **제출하기**: 번호·이름·가락·조건 충족 여부가 선생님 시트의 '기록표' 탭에 번호 순서대로 기록됩니다.

## 반마다 자기 시트에 저장하기

페이지 하나를 모든 반이 함께 쓰고, 학생용 링크 끝의 `?c=…`가 어느 선생님 시트에 저장할지를 정합니다. 다른 반 선생님도 아래 설정을 하면 그 반 기록은 그 선생님 시트에만 저장됩니다.

1. [기록표_양식.xlsx](기록표_양식.xlsx)를 내려받아 구글 드라이브에 올리고, 구글 시트로 엽니다. 이미 기록표가 있으면 그 시트를 써도 됩니다. 탭 이름은 `기록표`, 1번 학생은 5번째 줄이어야 합니다.
2. 시트 메뉴에서 **확장 프로그램 → Apps Script**를 열고 [apps-script/Code.gs](apps-script/Code.gs) 내용을 붙여 넣은 뒤 저장합니다. 웹앱 아래쪽 '선생님 설정'에도 같은 코드와 복사 버튼이 있습니다.
3. **배포 → 새 배포 → 웹 앱**을 고르고, 실행 사용자는 **나**, 액세스 권한은 **모든 사용자**로 두고 배포합니다.
4. 나온 웹 앱 URL을 웹앱의 '선생님 설정'에 붙여 넣고 **연결 확인** → **우리 반 학생용 링크 만들기**를 누릅니다.
5. 만들어진 링크를 학생들에게 나눠 줍니다.

같은 번호로 다시 제출하면 그 줄이 새 가락으로 바뀌고, I열에 제출 시각이 남습니다.

## 배포 (GitHub Pages)

저장소 **Settings → Pages**에서 *Deploy from a branch*를 고르고, 이 브랜치의 `/ (root)`를 선택하면 `https://<아이디>.github.io/doraji/`에서 열립니다. 빌드 과정이 없는 HTML 파일 하나(`index.html`)라 그대로 올라갑니다.
