# 나만의 도라지타령

초등 음악 창작 수행평가([6음03-02])용 웹앱입니다. 학생들은 율명을 단소 소리로 듣고, 경기민요 「도라지타령」의 마지막 줄 가락을 바꿔 보고, 자기 가락이 들어간 노래 전체를 들어 봅니다. 다 만든 가락은 제출하고, 선생님은 반별 기록을 Word나 PDF로 내려받습니다.

## 기능

- **율명 소리 듣기**: 중·임·무·청황·청태·청중·청임을 누르면 단소 음색의 소리가 납니다.
- **마지막 줄 가락 바꾸기**: 교과서 정간보 빈칸 12칸에 율명을 넣습니다. "같은 음이나 바로 위·아래 음으로만 이동" 조건을 자동으로 확인합니다.
- **전체 노래 듣기**: 원래 노래와 내가 바꾼 노래를 정간보를 따라가며 들을 수 있습니다. 빠르기도 조절할 수 있습니다.
- **제출하기**: 학생이 처음에 학년·반·번호·이름을 적고, 가락을 다 만든 뒤 발표 방법(단소/노래)을 골라 제출합니다. 기록은 Supabase에 저장됩니다.
- **선생님 페이지** (`teacher.html`): 교사 비밀번호와 학년·반을 넣으면 그 반의 만든 가락, 빈칸 모두 채움, 음 이동 규칙, 발표 방법, 제출 시각을 표로 보고 **Word(.doc)로 내려받거나 PDF로 저장**할 수 있습니다.

## 저장 공간 설정 (Supabase, 처음 한 번)

1. Supabase 프로젝트의 **SQL Editor**에서 [supabase/setup.sql](supabase/setup.sql)을 실행합니다. 맨 아래 `'여기에_비밀번호'`를 교사 비밀번호로 바꿔서 실행하세요.
2. 프로젝트 주소와 공개(publishable/anon) 키를 [config.js](config.js)에 넣습니다. service_role/secret 키는 넣지 마세요.

학생 기록은 공개 키로 직접 읽을 수 없고, 교사 비밀번호가 맞을 때만 `doraji_list` 함수로 볼 수 있습니다. 비밀번호를 바꾸려면 setup.sql의 마지막 문장만 새 비밀번호로 다시 실행하면 됩니다.

## 배포 (GitHub Pages)

저장소 **Settings → Pages**에서 *Deploy from a branch*를 고르고, 이 브랜치의 `/ (root)`를 선택하면 `https://<아이디>.github.io/doraji/`에서 열립니다. 빌드 과정이 없는 HTML 파일 하나(`index.html`)라 그대로 올라갑니다.
